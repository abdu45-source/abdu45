# Files

This directory contains downloadable files shared from this profile.

## How to attach a file

1. Add your file (e.g., `resume.pdf`) to this `files/` directory.
2. Commit and push the file to the repository.
3. It will be accessible via a direct link from the README.

**Example link format:**
```
https://github.com/abdu45-source/abdu45/raw/main/files/resume.pdf
```
